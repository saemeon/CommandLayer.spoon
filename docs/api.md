# Command Layer reference

Generated by `lua tests/reference.lua` from `core/schema.lua`, `core/api.lua` and the plugins
that ship. Do not edit it: change those and generate it again. The harness fails while it is out of date.

## Specs

### command

A verb with a stable id, contributed by an extension and always run by id.

| Field | Type | Required | Description |
|---|---|---|---|
| `after` | string |  | What the picker does once the command has run: close the layer (when absent), keepOpen and redraw where it was picked, or go back a level from there. One of `close`, `keepOpen`, `back`. |
| `args` | table |  | The args given to command; their templates are filled from the context. |
| `category` | string |  | Groups the command: its row reads Category: Title, and the category is matched too. |
| `command` | string |  | Another command to run instead. |
| `confirm` | string or function |  | Asked, yes or no, once every input is answered and before it runs: a template filled like targetName, or a function (args, ctx) returning the question, or nil to run without asking. |
| `enablement` | when clause |  | Shows the command as Unavailable, and refuses it, while it does not hold. |
| `icon` | string |  | A ThemeIcon, $(name). |
| `id` | string | yes | Dotted, and starting with the extension's name: git.clone. |
| `inputs` | list of inputs |  | What the command asks for before it runs. |
| `menus` | table |  | Where the command is a row: a list of menu names, or a table from a name to true or { when }. { "commandPalette" } when absent; {} is no row. |
| `prefix` | string or list of strings |  | Typing this opens a picker holding the command alone; a list gives several. |
| `rank` | number |  | How particular the command is to now, 0..1, for the specificity ranker. |
| `run` | function |  | function(args, ctx): what the command does. |
| `targetName` | string or function |  | Names what the command acts on in its row, Title -- target: a template filled from the context and the answers -- ${input:window.app} -- counting what a preferCurrent input takes; or a function (args, ctx). Nothing when empty. |
| `title` | string | yes | What its row reads; ${query} shows what was typed. |
| `when` | when clause |  | Hides the command while it does not hold. |

### extension

| Field | Type | Required | Description |
|---|---|---|---|
| `after` | string or list of strings |  | Extensions it runs after. |
| `before` | string or list of strings |  | Extensions it runs before, in capture, gather and search. |
| `capture` | function |  | function(ctx): fields it adds to the context. |
| `commands` | list of commands |  | The commands it contributes. |
| `description` | string |  | What the extension is for; heads its part of Default Settings. |
| `displayName` | string |  | What a person reads; the name capitalised when absent. |
| `exports` | table |  | What cl.extension(name) gives an extension declaring this one a dependency. |
| `extensionDependencies` | list of strings |  | Extensions it cannot work without: it is dropped while one is not loaded. |
| `items` | function |  | function(ctx, opts): its rows, the nouns. |
| `left` | function |  | function(ctx): told when a level its rows feed comes off the stack -- back, closed, or replaced -- never when a level opens over it, so it can stop what it started for that picker; activeView in ctx is the picker left. |
| `menus` | list of strings |  | The menus its items feed. |
| `name` | string | yes | The extension's name, which is its file's. |
| `optionalExtensionDependencies` | list of strings |  | Extensions it uses when they are loaded, and starts after. |

### input

What a command asks for before it runs, as VS Code's tasks.json declares inputs: a picker that asks it, or a command whose result answers it. The answer is args[id], and ${input:id} in a template.

| Field | Type | Required | Description |
|---|---|---|---|
| `args` | table |  | The args that command is run with. |
| `command` | string |  | The command whose result answers the input, as VS Code's command input; instead of picker. |
| `current` | function |  | function(ctx): what is in front, answering the input without asking when the command is run by id. |
| `default` | any |  | Offered first: what a typed picker answers with nothing typed, the first of a picker's options. |
| `description` | string |  | The prompt shown while asking. |
| `encode` | string |  | How typed text is encoded before it fills a template: query for a URL's query string. |
| `fromQuery` | boolean |  | Answered by what was typed, so the command runs straight from the search field; its picker is typed. |
| `id` | string | yes | The name the answer is given under. |
| `pattern` | string |  | A Lua pattern a typed answer must match; one that does not keeps the prompt open, saying so. |
| `picker` | table |  | The picker that asks it, whose row picked -- its value, else its subject -- is the answer: options, strings or { label, description, iconPath, value }, or a function (ctx, args) giving them; when, a clause over a row -- viewItem is its subject kind -- taking the rows it holds for from menus (every menu when absent), which also makes the command a verb on those rows' cmd+k; kind "search" with search(query, ctx, args, done), asking again as you type; typed = true, answered by what was typed. |
| `preferCurrent` | boolean |  | Answer with current when the command's row is picked too, asking only when nothing is in front. |
| `validate` | function |  | function(value, ctx, args): why the answer will not do, as text, keeping the prompt open; nil when it will. |

### row

What a picker shows, in VS Code's quick pick names. Rows are made as a picker opens, so only the harness checks them.

| Field | Type | Required | Description |
|---|---|---|---|
| `alwaysShow` | boolean |  | Kept whatever is typed, as VS Code's QuickPickItem.alwaysShow: no matcher drops it, and with text typed it follows the ranked rows, in the order given. |
| `args` | table |  | The args that command is run with. |
| `command` | string |  | The command picking it runs. |
| `ctx` | table |  | The context the row was made in. |
| `description` | string |  | The start of the second line. |
| `detail` | string |  | The rest of the second line. |
| `enabled` | boolean |  | false shows the row as Unavailable, and refuses it. |
| `icon` | any |  | A ThemeIcon, $(name). |
| `iconPath` | any |  | An image, or $(name). |
| `keepOpen` | boolean |  | Picking it runs its action and redraws the picker, rather than closing the layer. |
| `keywords` | list of strings |  | A list of words the row is also found by, beside its label -- a URL, a bundle id -- matched up to 160 characters, and graded below a match in the label. |
| `kind` | string |  | separator makes the row a label for the row after it. One of `separator`. |
| `label` | string |  | The first line; a leading $(name) is its icon. Every row but a separator has one. |
| `rank` | number |  | How particular the row is to now, 0..1. |
| `run` | function |  | function(ctx): what picking it does, instead of a command. |
| `source` | string |  | Set by the layer: the extension the row came from, which sections select on. |
| `subject` | table |  | What the row is, { kind, ... }: what cmd+k offers verbs for, and frecency remembers. |
| `submenu` | string |  | The picker picking it opens over the current one. |
| `submenuQuery` | string |  | The text that picker opens with, as if typed. |
| `value` | any |  | In a command's question, what picking it answers; the row's subject when absent. |
| `when` | when clause |  | Hides the row while it does not hold. |

| Field | Type | Required | Description |
|---|---|---|---|

## Settings

A profile's `settings.json` sets any of these over `config/defaults.jsonc`. An editor completes and
checks it when it starts with `"$schema"` naming the Spoon's `config/settings.schema.json`; VS Code's
`json.schemas` setting does the same for `keybindings.json` with `config/keybindings.schema.json`.

### The kernel's

| Key | Type | Default | Description |
|---|---|---|---|
| `actionsView` | string | `"actions"` | The picker cmd+k opens for the highlighted row. |
| `aliases` | object | `{}` | Aliases of your own, a string or a list, by command id: { "windows.leftHalf": "lh" }. Typed as the whole query, ignoring case, an alias puts its command's row first, whatever the rankers score. |

| `appearance.dark` | boolean | `true` | Dark pickers. |

| `appearance.rows` | number | `12` | How many rows a picker shows at once. |
| `appearance.width` | number | `36` | A picker's width, in percent of the screen's. |

| `performance` | object | `{ "keep": 200, "slowMilliseconds": 250 }` | Where the time goes: a line per open and keystroke at debug, every span at trace, and "Developer: Show Performance". |
| `performance.keep` | number | `200` | How many of the latest spans are kept. |
| `performance.slowMilliseconds` | number | `250` | A span or a whole open taking this long is a warning; 0 records nothing. |
| `prefixes` | object | `{}` | Prefixes of your own, added to a picker's by its name: { "recent": "r " }. |
| `presenter` | string | `"chooser"` | The presenter drawing a picker that names none. |
| `rankers` | object | `{ "alphabetical": 0, "frecency": 0.2, "relevance": 1, "specificity": 0.35 }` | Each ranker's weight. Every ranker scores a row 0..1, so its weight is the whole of how much it counts; one at 0 records nothing. |
| `tools` | object | `{ "loginShell": true, "paths": {}, "use": {} }` | Where tools are, and which provider does a job. |
| `tools.loginShell` | boolean | `true` | Whether start asks a login shell once for tools the known paths missed. |

| `tools.use` | object | `{}` | Which provider does a job: { "editor": "zed" }. |
| `useDefaultProfile` | object | `{ "keybindings": false }` | In a profile other than default: what it takes from the default profile, as VS Code's "Use Default Profile" does. |
| `useDefaultProfile.keybindings` | boolean |  | The default profile's keybindings.json, before this profile's own. |
| `views` | array |  | Pickers, merged by name: an entry changes the fields it names, and a new name adds one. |

## Keybindings

`keybindings.json` is a list of entries, each after the shipped `config/defaultKeybindings.jsonc`.

| Field | Required | Description |
|---|---|---|
| `args` |  | The args the command is run with; quickOpen takes { view, query }. |
| `command` | yes | The command it runs. -id removes the entries before it for that command: only those for key when one is named, every one otherwise. |
| `global` |  | Whether the key works in every app, while the layer is closed too, rather than only while it is open. A global key's when is checked against a context made when it is pressed. { "key": "alt+space", "command": "quickOpen", "global": true } enters the layer. |
| `key` |  | The chord: modifiers and one key joined by +, as cmd+shift+p; hyper is cmd+alt+ctrl+shift. A key the search field needs to edit text -- a letter, space, backspace, left, cmd+a, cmd+v -- is a problem and is not bound. |
| `repeat` |  | Whether holding the key runs the command again as the key repeats; true when absent for quickOpen.selectNext and quickOpen.selectPrevious. |
| `when` |  | The entry applies only while this holds, checked when the key is pressed against the picker on screen, with activeView, hasQuery (text in the field after any prefix) and viewItem (the highlighted row's kind). Of the entries on one key the last whose when and whose command's enablement hold runs. |
